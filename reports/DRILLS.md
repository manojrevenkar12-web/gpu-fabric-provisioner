# Drill results

Generated by `go run ./cmd/drill`. Every run uses a fresh kube-apiserver and etcd (envtest), the simulated
cloud, kubelets and scheduler in `internal/sim`, and the same workload for both provisioners. GPU-seconds
are counted from the cloud's instances (paid) and from running pods (useful) until the last job finished.
Timings are compressed: servers boot in 1.5–3 s and advertise GPUs 2 s after registering.
A gang whose members land in different fabrics is assumed to run 3× slower (its collectives leave InfiniBand);
its GPU time is not counted as useful.
